# Implementation roadmap

## Phase 1 — Foundation
Next.js, SQLite, seed, semantic YAML, basic API. Exit: `/api/analytics/query` executes a QueryPlan.

## Phase 2 — Analytics engine
Parser, QueryPlan schema, validation, SQL compiler, execution.

## Phase 3 — Copilot
Chat UI, agent, tools, conversation persistence.

## Phase 4 — Evidence and visualisation
Evidence object, chart recommendation, ECharts, comparisons.

## Phase 5 — Dashboard
DashboardSpec, renderer, save, agent tools.

## Phase 6 — SDD showcase
Specification trace page, acceptance tests, runtime traces.
