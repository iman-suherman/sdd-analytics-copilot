# SDD Analytics Copilot

Spec-driven AI analytics SaaS demo with a Copilot-style agent, governed SQLite queries, semantic metrics, and AI-generated dashboards.

**SDD Analytics Copilot** is a reference implementation demonstrating Spec-Driven Development for agentic software.

Users can ask natural-language questions about a seeded SQLite dataset, inspect the governed query plan generated by the AI agent, explore evidence-backed results, and create dashboards conversationally.

Every major capability is traceable from requirement and acceptance criteria through implementation, automated tests, and runtime agent traces.

## Hero flow

```
Ask
"Kenapa pendapatan turun bulan lalu?"
             ↓
Plan
Metric: revenue
Comparison: previous month
Breakdown: region + segment
             ↓
Execute
Governed semantic queries against SQLite (company_id scoped)
             ↓
Explain
"Pendapatan turun … terutama didorong Sumatera."
             ↓
Visualise
Evidence-backed charts in the floating Kopilot dock
             ↓
Persist
"Tambahkan investigasi ini ke dasbor eksekutif"
```

## Quick start

```bash
npm install
npm run login   # optional — Vertex for Copilot
npm run demo
```

Open [http://localhost:3000](http://localhost:3000).

`npm run db:seed` loads commerce data from `data/samples/` (CSV per company with sector-specific columns). Regenerate those files from SQLite with `npm run data:export-csv`. Use `npm run db:seed:generate` to rebuild procedurally without CSVs.

If application code is missing, use:
